# Cold-start-to-first-export benchmark

The headline acceptance gate for the project: a fresh clone + `docker
compose up` to downloaded MP4 in under 15 minutes.

## Procedure

1. **Host:** 4 vCPU, 8 GB RAM, fresh Docker install. Ubuntu 22.04 LTS is
   the canonical target.
2. Start stopwatch at `git clone`.
3. `cp .env.example .env` + paste `ANTHROPIC_API_KEY`.
4. `docker compose up -d` — build images, bring up stack.
5. Wait until `curl -fsS http://localhost:8001/health | jq .status` returns
   `"ok"`.
6. Open `http://localhost:3000/`, create a project.
7. Drop in a ~2-minute test video (we use the synthetic 120-s fixture
   in `data/inbox/long_120s.mp4` generated by
   `assets/music/synthesize_placeholders.sh`-style ffmpeg commands for
   local benchmarks).
8. Click **Analyze footage**, then **Select reels**, then **Compose reel**
   on rank 1. Accept defaults everywhere.
9. Click **Export** → **mp4_h264_social**.
10. Click **Download**.
11. Stop stopwatch when the file lands.

## Budget

| Phase                             | Target      |
|-----------------------------------|-------------|
| `docker compose build` cold cache | ≤ 8 min     |
| First `analyze` (incl. base.en dl)| ≤ 3 min     |
| `select` (one Claude call)         | ≤ 1 min     |
| `compose` (defaults, no effects)  | ≤ 1 min     |
| `export` (mp4_h264_social)         | ≤ 1 min     |
| **Total**                          | **≤ 15 min**|
